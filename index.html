Featured · Jan 2026

Low-VRAM AI Video Pipeline

Structured input goes into a Google Sheet; a finished cinematic video comes out — on an 8GB VRAM, 32GB RAM desktop instead of a rented A100. n8n handles scheduling, conditional logic and error recovery. Ollama (Qwen2.5-7B, Llama 3) writes JSON storyboards with scene numbers, durations and per-shot prompts. ComfyUI runs three stages: text-to-image, image-to-image scene adaptation, then image-to-video with LTX 2.0. Character consistency holds across scenes through a base reference image with USO conditioning.

Multi-Modal Emotion Recognition

Faces lie less when you also listen. This system reads facial expression and speech together, runs a CNN over each modality, and fuses them at feature level with global average pooling before classification — beating both single-modality baselines. The work became an IEEE-published paper.
